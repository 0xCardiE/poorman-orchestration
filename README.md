# Poorman AI orchestration

This repo is a lightweight orchestration setup for running an AI coding agent (e.g. Codex) over a task queue: **AGENTS.md**, **PLANS.md**, and **tasks/todo/** define the work; **run.sh** runs the loop. The current project built with it is the app below.

---

## Niche Research Digest

Niche Research Digest is a local-first web app for collecting sources, organizing research by topic, linking claims across sources, and producing concise topic digests.

## Capabilities

The MVP currently includes:

- a single-page dashboard with navigation for sources, topics, claims, and digests
- source capture with title, URL, type, publisher, date, topics, tags, notes, manual summary, and takeaways
- topic creation and editing with name, description, tags, and open questions
- topic views that collect linked sources and claims, surface shared tags, and show lightweight related-topic connections
- claim capture with explicit source evidence and support, contradict, or neutral links to other claims
- digest views that show recent additions, unresolved questions, and explicit contradictions for each topic
- shared search and filters across source, topic, claim, and digest views
- local-first persistence in `localStorage`
- JSON import and export for moving a workspace snapshot between browsers
- seeded demo data plus a reset action for quickly restoring a working sample workspace

The app stays intentionally rule-based. Digests are derived from saved records, not generated by a model: recent items come from timestamps, unresolved questions come from saved prompts and evidence-gap checks, and conflicts only appear when a claim explicitly contradicts another claim.

## Setup

Use Node.js 20+ or a current LTS release.

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local Vite URL shown in the terminal. On first load the app seeds a demo workspace into `localStorage`.

## Available commands

```bash
npm run dev
npm run build
npm run preview
npm run lint
npm run test
```

## Testing and verification

- `npm run test` runs the Vitest suite for workspace, filtering, topic, source, claim, and digest logic.
- `npm run lint` checks the TypeScript and React code with ESLint.
- `npm run build` runs `tsc -b` and produces the production Vite bundle in `dist/`.

## Notes

The app writes a seeded demo workspace into `localStorage` on first load and includes a reset action to restore that demo state. Importing a workspace replaces the current in-browser data with the selected JSON snapshot.

Topic organization stays intentionally lightweight: sources can belong to multiple topics, and topic relationships are inferred from those shared source assignments instead of a nested taxonomy.

The workspace toolbar applies one shared search and filter state across the source, topic, claim, and digest sections, so the digest view reflects the same narrowed workspace the other sections are using.
