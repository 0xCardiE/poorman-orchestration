Goal:
- Add topic and tag organization on top of the source library.

Acceptance criteria:
- Add topic pages or views that group related sources.
- Show tags and recent additions for each topic.
- Make it easy to move between a topic and its related sources.
- Keep topic relationships readable and lightweight.
- Confirm the app still builds successfully.

Constraints:
- Do not build nested taxonomy systems.
- Keep navigation simple.
- Reuse the existing data model where possible.
